# ApnaStore - Fashion Website
    ApnaStore is a mini e-commerce fashion website built using *HTML, CSS, and Flask (with MySQL backend)*.  
    It includes different sections for Men's, Women's, Kids, and more, along with a working search bar and login system.

# 🚀 Features
- 👕 Men’s, Women’s, Kids & More categories  
- 🔍 Working search bar  
- 🔑 Login & Signup system (MySQL + SQLAlchemy)  
- 🛒 Add to cart & product management
- 🤖 Mini AI ChatBot Helps To find Information About Apnastore
- 📱 Responsive design with HTML & CSS  

# 🛠️ Tech Stack
- *Frontend:* HTML5, CSS3, javascript  
- *Backend:* Flask (Python)  
- *Database:* MySQL with SQLAlchemy  
- *Version Control:* Git & GitHub
